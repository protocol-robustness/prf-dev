# Repository ownership

prf-dev is the common developer and reviewer interface for reproducible, inspectable, independently verifiable work across PRF repositories. It does not become another source of protocol authority.

| Area | Owner | prf-dev role |
|---|---|---|
| Protocol semantics and canonical evidence hashing | PRF framework | Invoke the registered canonical hash contract |
| Deployment plans, execution and deployment verification | protocol-deployments | Snapshot identity and delegate checks |
| Agent orchestration and runtime workflow | Symphony | Interoperate through component-owned records |
| Routine signed agent submissions and staging | PRO-106 / Symphony | Adapter and independent verification entry points |
| Protected history repair and publication authority | PRO-90 | Compatible schemas, fixtures, verifier adapter |
| Cross-repository command ownership | PRO-74 | Common CLI without duplicating owner commands |
